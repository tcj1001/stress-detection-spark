# 压力检测数据分析系统 — 前端页面功能说明

## 系统概述

本系统基于 Fitbit 可穿戴设备采集的生理行为数据（心率、睡眠、步数、卡路里、活动强度等），通过 Spark 大数据分析计算综合压力评分，并使用四种分析模型对用户健康风险进行评估和预测。前端采用 Vue 3 + Element Plus + ECharts 构建，整体采用玻璃拟态（Glassmorphism）暗色风格。

### 系统角色

| 角色 | 说明 |
|------|------|
| 管理员 | 账号 admin，可访问所有页面，包括"用户管理" |
| 普通用户 | 通过注册创建，可访问除"用户管理"外的所有数据分析页面 |

### 四种分析模型

| 模型 | 中文名称 | 算法 | 准确率 |
|------|----------|------|--------|
| WeightedScoring | 综合压力评估 | 加权评分规则（心率25%+久坐30%+睡眠25%+活动20%） | 69.9% |
| TrendAnalysis | 趋势分析 | DecisionTreeClassifier 决策树 | 89.1% |
| CorrelationAnalysis | 相关性分析 | LogisticRegression 逻辑回归 | 86.1% |
| KMeansClustering | K-Means聚类 | KMeans(k=3) 聚类标签映射 | 54.9% |

### 风险等级划分

| 等级 | 压力评分范围 | 颜色标识 |
|------|-------------|---------|
| 高风险 | ≥65分 | 红色 |
| 中风险 | 40~65分 | 橙色 |
| 低风险 | <40分 | 绿色 |

## 一、登录页面

用户通过账号和密码登录系统。登录成功后，系统保存用户的身份信息（Token、账号、用户名、角色），并根据角色决定可见的菜单项。

页面底部提供两个入口：
- **修改密码**：弹出对话框，输入账号、原密码和新密码即可修改，无需登录
- **立即注册**：跳转至注册页面

新用户注册需填写三个字段：

| 字段 | 说明 | 要求 |
|------|------|------|

| 账号 | 用于登录的唯一标识 | 必填，3~50位 |
| 密码 | 登录密码 | 必填，至少6位 |

## 三、总览仪表盘

进入系统后的首页，展示全局数据概览。

### 3.1 统计卡片（4个）

| 卡片 | 含义 |
|------|------|
| 监测用户数 | 系统中有压力评分数据的用户总数（来自数据集中的33位 Fitbit 用户） |
| 高风险人次 | 所有用户所有天数中，压力评分≥65的记录总数 |

| 低风险人次 | 压力评分<40的记录总数 |

> 注：一个用户在不同日期可能处于不同风险等级，因此统计的是"人次"而非"人数"。

### 3.2 风险等级分布饼图

环形饼图，展示高风险、中风险、低风险三类记录在所有943条每日评分中的占比。可以直观看出整体人群的健康压力分布情况。

### 3.3 用户聚类分布柱状图

展示 K-Means 聚类后三类用户群体的平均压力分对比：
- **高压久坐型**：平均压力分最高，久坐比例大
- **睡眠不足型**：睡眠效率低，压力中等
- **健康活跃型**：平均压力分最低，运动活跃

## 四、每日压力分析

按用户查看每日压力评分的详细数据，分为**压力趋势**和**模型预测对比**两个部分。

### 4.1 压力评分趋势折线图

通过顶部下拉框选择用户后展示：
- **实线**：该用户每天的原始压力评分（0~100分）
- **虚线**：7日滑动平均线，用于平滑波动，反映中期趋势

### 4.2 各维度压力分明细（堆叠柱状图）

将每天的压力评分拆分为四个维度的分值明细：

| 维度 | 含义 | 权重 |
|------|------|------|
| 心率压力分 | 静息心率越高，说明交感神经越兴奋，压力越大 | 25% |
| 久坐压力分 | 一天中久坐时间占比越高，身体缺乏活动，压力越大 | 30% |
| 睡眠压力分 | 睡眠效率越低（翻动/清醒时间多），恢复不足，压力越大 | 25% |
| 活动压力分 | 代谢当量（METs）越低，活动强度不足，压力越大 | 20% |

### 4.3 四模型风险预测对比

选择用户后展示四个模型对该用户每日风险等级的预测结果：

- **准确率卡片（4个）**：分别显示四个模型对该用户预测的准确率百分比
- **预测时间线图**：横轴为日期，纵轴为风险等级（低=0、中=1、高=2），实线代表实际风险，散点代表各模型的预测值，圆点为预测正确、三角为预测错误
- **预测正误分布饼图**：各模型预测正确的次数对比
- **逐日预测明细表**：每一天的实际风险等级与四个模型的预测结果逐条展示，预测错误的单元格标红叉号

## 五、趋势分析

对用户压力评分的时间变化趋势进行分析，并提供未来7天的预测。

### 5.1 压力变化趋势折线图

展示选定用户的每日压力评分及其7日滑动均线，观察长期走势。

### 5.2 日环比变化率柱状图

每天相对于前一天的压力评分变化率（百分比）：
- **红色柱子**：压力上升（变化率为正）
- **绿色柱子**：压力下降（变化率为负）

可以快速识别压力剧烈波动的日期。

### 5.3 未来趋势预测

基于历史数据，使用线性回归 + EWMA（指数加权移动平均）混合方法预测未来7天的压力走势。

#### 摘要卡片（4个）

| 卡片 | 含义 |
|------|------|
| 当前压力分 | 该用户最后一天的实际压力评分 |
| 预测均值 | 未来7天预测压力分的平均值 |
| 趋势方向 | 预测趋势的方向：上升（红色箭头）/ 下降（绿色箭头）/ 平稳（蓝色横线） |
| 日均变化率 | 预测线性回归的斜率，正值代表压力趋势上升 |

#### 预测折线图

将历史实际数据（蓝色实线）与未来7天预测数据（橙色虚线）绘制在同一张图上：
- 预测线上的每个点用颜色标注对应的风险等级（红/橙/绿）
- 灰色虚线标出置信区间的上下界，表示预测的不确定性范围

#### 逐日预测明细表

| 列 | 含义 |
|----|------|
| 预测日期 | 未来7天的日期 |
| 预测压力分 | 模型预测的压力评分 |
| 置信区间 | 预测值的上下界范围 |
| 预测风险等级 | 根据预测分值划分的风险等级（高/中/低） |
| 相对变化 | 与当前实际压力分的差值，红色表示升高、绿色表示降低 |

## 六、相关性分析

分析压力评分与各生理行为指标之间的 Pearson 相关性，找出影响压力的关键因素。

### 6.1 分析的7个特征维度

| 特征 | 中文名 | 含义 |
|------|--------|------|
| stress_score | 压力评分 | 综合压力评估结果（0-100分） |
| resting_hr | 静息心率 | 静息状态下的平均心率 |
| sleep_efficiency | 睡眠效率 | 实际入睡时间占总卧床时间的比例 |
| sedentary_ratio | 久坐比例 | 久坐不动时间占全天的比例 |
| active_minutes | 活动时长 | 每天中等及以上强度运动的分钟数 |
| total_steps | 总步数 | 每天的总步数 |
| calories | 卡路里 | 每天消耗的总卡路里 |

### 6.2 Pearson 相关系数热力图（全矩阵 + 上三角）

7×7 的矩阵，每个单元格显示两个特征之间的 Pearson 相关系数（-1 到 +1）：
- **红色（接近+1）**：强正相关，两个指标同升同降
- **蓝色（接近-1）**：强负相关，一个升高另一个降低
- **白色（接近0）**：几乎无线性关系

上三角矩阵是同样的数据，去掉了冗余的对称部分，更清晰地展示唯一的特征对。

### 6.3 与压力评分的关联强度柱状图

将其余6个特征按照与 stress_score 的相关系数绝对值从大到小排列：
- **红色**：正相关（该指标越高，压力越大）
- **蓝色**：负相关（该指标越高，压力越低）

### 6.4 最显著相关特征对

在非 stress_score 的特征之间，找出相关性绝对值最大的前6对，展示哪些生理指标之间存在较强的联动关系。

### 6.5 关键发现摘要

系统根据相关系数自动生成6类文字洞察：

| 类别 | 含义 |
|------|------|
| 核心发现 | 与压力评分相关性最强的单一特征 |
| 正相关 | 与压力呈正相关的特征（r > 0.2），这些指标升高时压力增大 |
| 负相关 | 与压力呈负相关的特征（r < -0.2），这些指标升高时压力降低 |
| 特征联动 | 非压力特征之间的最强关联（如运动与卡路里高度正相关） |
| 独立因素 | 与压力几乎无关的特征（\|r\| < 0.15） |
| 健康启示 | 久坐比例与睡眠效率之间关系的健康建议 |

| 类型 | 特征 |

展示每个用户所属的聚类类型、平均压力分和风险等级。

## 八、时段规律

分析每个用户在一天24小时中的活动模式。

### 8.1 各时段平均步数与卡路里（双轴柱状图）

通过用户选择器选择用户后展示：
- **蓝色柱子（左轴）**：该用户在每个小时（0-23时）的平均步数
- **橙色柱子（右轴）**：该用户在每个小时的平均卡路里消耗

可以看出用户在一天中哪些时段最活跃（通常为上午和下午的通勤/运动时间），哪些时段是静息状态。

### 8.2 各时段平均活动强度（面积折线图）

绿色面积图展示每小时的平均活动强度（intensity 值），从另一个角度反映用户的日内活动规律。强度值高的时段说明用户在进行较大强度的运动或活动。

## 九、模型性能对比

对四种分析模型作为风险等级分类器的性能进行全面对比分析。

### 9.1 准确率卡片（4个）

每个模型一张卡片，显示其在5折交叉验证下的总体准确率。

### 9.2 分类性能指标对比（分组柱状图）

四个评估指标并排对比：

| 指标 | 含义 |
|------|------|
| 准确率（Accuracy） | 所有预测中正确预测的比例 |
| 精确率（Precision） | 预测为某个风险等级的样本中，实际确实是该等级的比例 |
| 召回率（Recall） | 实际为某个风险等级的样本中，被模型正确识别出来的比例 |
| F1分数（F1-Score） | 精确率和召回率的调和平均值，综合衡量模型性能 |

### 9.3 学习曲线

展示每个模型在不同训练样本量下的测试准确率变化：
- 横轴为训练集大小（从少到多）
- 纵轴为测试集准确率
- 曲线上升并趋于平稳说明模型收敛良好
- 四条曲线使用不同线型（实线、虚线、点线、点划线）和形状标记以便区分

### 9.4 混淆矩阵热力图（4个）

每个模型一个 3×3 矩阵：
- 行（Y轴）：实际风险等级（高/中/低）
- 列（X轴）：模型预测的风险等级
- 对角线上的数值越大越好，说明预测准确
- 非对角线上的数值代表误分类的数量

### 9.5 预测分布对比（堆叠柱状图）

将实际的风险等级分布与四个模型预测的分布进行对比。如果模型的分布柱与"实际"柱接近，说明模型的预测分布合理。

### 9.6 预测正误统计（堆叠柱状图）

每个模型的预测正确和错误数量对比，绿色为正确、红色为错误。

### 9.7 各风险等级 F1 分数与召回率对比（折线图）

将四个模型在高风险、中风险、低风险三个等级上的 F1 分数和召回率分别绘制折线。可以看出各模型对哪种风险等级的识别能力更强或更弱。

### 9.8 特征重要性（4组水平柱状图）

每个模型单独一张图，展示对该模型决策最重要的特征及其相对重要性百分比。不同模型依赖的特征可能完全不同，例如：
- 综合压力评估依赖四个权重维度
- 趋势分析依赖变化率和历史分值
- 相关性分析依赖与压力关联最强的Top5特征
- K-Means聚类依赖全部12维特征的聚类中心方差

## 十、用户管理（仅管理员可见）

管理员专属页面，用于管理系统中的普通用户账号。

### 10.1 用户列表

分页表格展示所有用户信息：

| 列 | 含义 |
|----|------|

| 功能 | 说明 |
